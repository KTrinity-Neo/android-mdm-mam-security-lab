# Android Device Enrollment

## Objective
To enroll my Infinix Note 30 Pro into ManageEngine MDM using Android Enterprise Work Profile enrollment, demonstrating how personal Android devices can be enrolled and managed in a BYOD environment.

## Device Information
- **Model:** Infinix Note 30 Pro
- **Operating System:** Android 14
- **Ownership:** Personal / BYOD
- **Management Platform:** ManageEngine MDM
- **Enrollment Method:** QR Code Enrollment
- **Management Type:** Android Enterprise Work Profile

## Tools and Technologies
- ManageEngine MDM platform
- ManageEngine MDM Self Service application
- Android Enterprise
- Laptop and Android smartphone
- Internet connection

## Procedure

1. Accessed the ManageEngine MDM dashboard on my laptop.
2. Initiated the Android device enrollment process.
3. Downloaded and installed ManageEngine MDM Self Service from Google Play Store.
4. Logged into the MDM Self Service application.
5. Scanned the enrollment QR code generated by the MDM platform.
6. Received the Work Profile Creation prompt on the Android device.
7. Proceeded with the Work Profile creation process.
8. Completed the device enrollment process.
9. Verified successful enrollment through the ManageEngine dashboard on my laptop.

**Status: Successful Enrollment**

The Infinix Note 30 Pro was successfully enrolled into the ManageEngine MDM platform using the QR-code enrollment process.

Further verification of Work Profile isolation and device management capabilities will be performed during subsequent lab stages.

## Security Relevance

Android Enterprise Work Profile enrollment supports BYOD security by separating work-related applications and data from personal applications and data.

This allows an organization to apply management controls to the work environment while maintaining separation from the user's personal environment.
