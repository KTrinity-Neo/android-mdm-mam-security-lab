# Android Mobile Device Management (MDM) and Mobile Application Management (MAM) Security Lab

## Project Overview

This project documents my practical exploration of Mobile Device Management (MDM) and Mobile Application Management (MAM) using ManageEngine Mobile Device Manager Plus and an Android smartphone.

The objective is to understand how organisations secure, monitor, manage and protect mobile devices and corporate applications, particularly in a Bring Your Own Device (BYOD) environment.

## Project Objectives

- Understand the differences between MDM and MAM.
- Practise Android Enterprise Work Profile enrollment.
- Configure mobile device security policies.
- Explore mobile application management.
- Understand BYOD security implementation.
- Monitor device compliance.
- Perform practical mobile security tests.
- Document findings and lessons learned.

## Security and Privacy Considerations

This laboratory uses a personal Android device. The experiments will focus on Android Enterprise Work Profile enrollment to maintain separation between personal and work environments.

No factory reset, full-device wipe or unnecessary access to personal information is intended.

Sensitive information, enrollment tokens, QR codes and personal identifiers will not be published.
